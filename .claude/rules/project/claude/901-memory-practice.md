# Memory practice standards

## Feedback memory

- Save a feedback memory only when the same mistake happens twice in the session, or the user explicitly corrects you
- Keep a feedback memory to 3 lines: the rule, a one-line Why, and a one-line How to apply
- Check for an existing memory entry on the same topic before creating a new one. Update it instead of duplicating
