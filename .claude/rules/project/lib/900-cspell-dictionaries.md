# Cspell dictionary standards

## Dictionaries

- Add a real term from a tool, library, or platform to `.cspell/technical.txt`
- Add a project-specific term to `.cspell/project.txt`
- Rewrite a flagged typo instead of adding it to either dictionary
- Keep both dictionary files sorted alphabetically
