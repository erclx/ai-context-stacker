# Wireframes

Per-surface ASCII layouts loaded on demand

- [Context Tracks panel](context-tracks-panel.md): Top panel in the Stackr activity bar, lists tracks and lets the user switch, create, rename, reorder, delete
- [Preview webview](preview-webview.md): Side panel showing the formatted output exactly as it would be copied to the clipboard
- [Staged Files panel](staged-files-panel.md): Bottom panel in the Stackr activity bar, shows files staged in the active track
- [Status bar](status-bar.md): Status bar item showing the active track name and total token count
